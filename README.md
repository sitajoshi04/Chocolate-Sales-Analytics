# Chocolate Sales Analytics Dashboard
----
## Project Overview
This project analyzes chocolate sales data using Microsoft Excel to evaluate sales performance, product trends, regional performance, and marketing-related metrics. It includes an analytical worksheet and a visual dashboard to support data-driven decision-making.
----
## Dashboard Preview
The Chocolate Sales Analytics Dashboard was developed in Microsoft Excel to present key sales metrics and business performance indicators in a single interactive view.
![Chocolate Sales Analytics Dashboard](image/Overview-Dashboard.png)
----
### Dashboard Highlights
- **KPI Cards:** Total sales, orders, boxes shipped, average order value (AOV), marketing spend, and discounts.
- **Monthly Sales Trend:** Tracks sales performance across the year.
- **Product Analysis:** Compares sales across chocolate products.
- **Geographical Analysis:** Visualizes sales distribution by country.
- **Sales Channel Analysis:** Compares Online, Retail, and Wholesale sales.
- **Salesperson Performance:** Highlights the top 10 salespeople by sales.
- **Marketing Analysis:** Examines the relationship between marketing spend and sales.
---
### Interactive Features
The dashboard includes slicers for Year, Channel, Country, and Product, allowing users to filter the analysis and explore different aspects of sales performance.
## Objectives
- Analyze overall sales performance using KPIs.
- Identify monthly sales trends.
- Compare sales across products, countries, and sales channels.
- Evaluate salesperson performance.
- Examine discounts, boxes shipped, and marketing spend.
- Present insights through a dashboard.

## Dataset Description
The dataset contains approximately 198,578 sales records and includes fields such as:
- Order ID and order date
- Product and country
- Sales channel and salesperson
- Discount percentage and price per box
- Marketing spend and boxes shipped
- Sales amount
----
## Key Performance Indicators
- Total Amount: 101,819,088.79
- Order Records: 198,578
- Total Boxes Shipped (net of negative entries): 27,711,054
- Total Marketing Spend: 18,914,583.41
- Average Discount: 13.08%
- Average Order Value: 512.74
Data Quality Note: KPI values reflect the calculations in the workbook. Negative shipment entries may represent returned orders, so their treatment should be verified. The Average Order Value calculation should also be checked to ensure it uses the appropriate order count and sales amount.
